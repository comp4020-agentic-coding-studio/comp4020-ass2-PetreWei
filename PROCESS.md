# Process overview

## What I built

**SLOP3092 *Try Again, Later*: twelve weeks on one decision, asked in a new context each week.** Something failed — should you try again, and how? It should exist because retrying is the most common response to failure and the least examined: it looks like diligence, and a client that retries a request the server already committed turns one charge into two.

## How I got here

### What had to stay true, and who checks it

**The spec is my record of what had to stay true about the course, written before the content.** Three decisions became checks ([`bc5a4be`](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-PetreWei/commit/bc5a4be)): twelve dated weeks, a distinct `failure_scenario` per session, tags no broader than the course's slice. `failure_scenario` is a field I invented, enforced by that check alone since the fixed schema passes unknown frontmatter through. The tag check began as a blocklist and I threw it away — it only catches phrasings I thought of — for one matching signal words, so "reliability engineering" trips it. I declined a ninth: a dangling `related:` reference already fails the build, so it could only ever report green — a check that cannot fail is not a sensor. The `decided_by` check ([`805be48`](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-PetreWei/commit/805be48)) asserts two halves: presence alone passes on twelve weeks that all ask the client, the shallow version of this course. I confirmed each half failed for the right reason: collapsing week 11 reports `no week hands the decision to: nobody`.

### The turning point: an inherited harness, not the generated one

**The turning point was inheriting a harness instead of patching the generated one, then hardening it against a subagent that pushed to `main`.** The generated file described this repo back to me; patching it was the obvious move. Instead I replaced it wholesale with the previous crit's harness, unedited ([`9c25807`](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-PetreWei/commit/9c25807)), then adapted that from the lecture notes ([`86ed47d`](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-PetreWei/commit/86ed47d)) and the tutor's Assignment 1 feedback, including the STAR form this file is written in ([`dae225f`](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-PetreWei/commit/dae225f)). The diff settled it: most of what I was patching re-derived, worse, rules the inherited file already had. The artefact is replaced each deliverable; the harness accumulates. That hardening was earned: a subagent told not to edit anything committed to `main` and pushed ([`b458a90`](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-PetreWei/commit/b458a90)); `git status` caught it, not its report. I reverted ([`dcef0d2`](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-PetreWei/commit/dcef0d2)), then constrained subagents structurally, not by instruction ([`d47ded0`](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-PetreWei/commit/d47ded0)): the prompt was never the control, since a subagent inherits Bash, while `Explore` has no Write and a worktree keeps commits off `main`. I cut that rule ([`da3c8cf`](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-PetreWei/commit/da3c8cf)): it came from one incident, and the fix lives in how I delegate.

### What no check could catch

**Reading the twelve weeks side by side found what eight green checks could not.** Every lecture body was its own session's sentences pasted verbatim ([`be38af6`](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-PetreWei/commit/be38af6)). Worse, eleven of twelve weeks named what the naive retry cost, then handed over a fix whose own price went unmentioned: the course committing the reflex it criticises. I revised the plan rather than the pages ([`dbb17b6`](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-PetreWei/commit/dbb17b6)), giving every session a fifth slot — the fix, and what it trades; prose was rejected as invisible to a marker reading one week. Two weeks were one idea twice; merging them freed the slot for a situation the course lacked. Code review later caught two image savings I had called free when both had a price ([`1d9f4fa`](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-PetreWei/commit/1d9f4fa)). The one thing I chose not to encode: whether twelve weeks add up to a course is nobody's check but the marker's, since twelve distinct failure scenarios can still be twelve shallow weeks, all green — so I re-read the site end to end rather than measure it.

# Process overview

## What I built

**SLOP3092 *Try Again, Later*: twelve weeks on one decision, asked in a new context each week.** Something failed — should you try again, and how? It should exist because retrying is the most common response to failure and the least examined: it looks like diligence, and a client that retries a request the server already committed turns one charge into two. Twelve situations, not twelve topics.

## How I got here

### What had to stay true, and who checks it

**The spec is my record of what had to stay true about the course, written before the content it constrains.** Three decisions became checks ([`bc5a4be`](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-PetreWei/commit/bc5a4be)): twelve dated weeks, a distinct `failure_scenario` per session, tags no broader than the course's slice. `failure_scenario` is a field I invented; since the fixed schema passes unknown frontmatter through, that check alone enforces it. The tag check began as a blocklist and I threw it away — it only catches phrasings I thought of — for one matching signal words, so "distributed systems" and "reliability engineering" both trip it. I declined a ninth: a dangling `related:` reference already fails the build, so it could only ever report green — a check that cannot fail is not a sensor. The later `decided_by` check ([`805be48`](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-PetreWei/commit/805be48)) asserts two halves: presence alone passes on twelve weeks that all ask the client, the shallow version of this course. I confirmed each half failed for the right reason: collapsing week 11 reports `no week hands the decision to: nobody`.

### The turning point: inheriting a harness instead of patching mine

**The turning point was giving up on my own harness: the artefact is replaced each deliverable, the harness accumulates.** I had 28 rules and was unhappy with them; the obvious move was another pass. Instead I deleted the lot, took the previous deliverable's `CLAUDE.md` verbatim ([`9c25807`](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-PetreWei/commit/9c25807)), and layered this assignment's rules on. The diff settled it: most of mine were worse re-derivations of rules already there. The same instinct fixed the worst failure: a subagent I had told not to edit anything committed to `main` and pushed ([`b458a90`](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-PetreWei/commit/b458a90)); `git status` caught it, not its report. I reverted ([`dcef0d2`](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-PetreWei/commit/dcef0d2)), then fixed it where it could not recur ([`d47ded0`](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-PetreWei/commit/d47ded0)): the prompt was never the control, since a subagent inherits Bash — `Explore` has no Write, and a worktree keeps commits off `main`. I then cut that rule too ([`da3c8cf`](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-PetreWei/commit/da3c8cf)): it came from one incident, and the fix lives in how I delegate.

### What no check could catch

**Reading the twelve weeks side by side found what eight green checks could not.** Every lecture body was its own session's sentences pasted verbatim ([`be38af6`](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-PetreWei/commit/be38af6)), visible above the fold, not just in metadata. Worse, eleven of twelve weeks named what the naive retry cost, then handed over a fix whose own price went unmentioned: the course committing the reflex it criticises. I revised the plan rather than the pages ([`dbb17b6`](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-PetreWei/commit/dbb17b6)), giving every session a fifth slot — the fix, and what it trades; prose was rejected as invisible to a marker reading one week. Two weeks were one idea twice, so I merged them and spent the slot on a situation the course lacked. Code review later caught two image savings I had called free when both had a price ([`1d9f4fa`](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-PetreWei/commit/1d9f4fa)). The one thing I chose not to encode: whether twelve weeks add up to a course is nobody's check but the marker's, since twelve distinct failure scenarios can still be twelve shallow weeks, all green — so the harness has me re-read the site end to end rather than measure it.
